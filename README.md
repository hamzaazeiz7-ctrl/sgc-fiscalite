# SGC Fiscalité

Suivi des déclarations fiscales et sociales (Tunisie), au design SGC.

- Accueil : à payer sous 30 jours, échéances proches, retards.
- Mensuelles / Trimestrielles / Annuelles : un récap par période, avec rectificatives (versions successives et écart à payer).
- Autres : taxation d'office et contrôles, calendrier fiscal, autres échéances.
- Excel : export et import au format des modèles SGC (récap mensuel/trimestriel, IS, acomptes). Word, PDF et CSV en export.
- Profil société repris de SGC Freelance Pilot ; données chiffrées (AES-GCM) et synchro GitHub privée.

## Publier sur GitHub Pages
Déposer tous les fichiers de ce dossier à la racine du dépôt public (le fichier .nojekyll compris), puis activer Pages. Les données vont dans un dépôt privé séparé, jamais dans ce dépôt.
